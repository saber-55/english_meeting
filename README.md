# Postgraduate English Interview Trainer

一个用于保研 / 考研复试中英文口语问答训练的网页应用。

本项目面向需要准备研究生推免面试、考研复试英语问答、导师面试英文交流的学生，帮助用户通过随机抽题、英文朗读、录音练习、参考答案对照和私人题库积累，提升英语口语表达的熟练度和临场反应能力。

## 功能特点

- 内置英文面试题库，覆盖自我介绍、学业背景、科研经历、项目经历、竞赛经历、读研规划、导师匹配、专业知识、压力问题和追问问题。
- 支持按题目分类、难度和题库来源随机抽题。
- 支持英文题目默认遮盖，并可手动显示英文原题和中文翻译。
- 点击下一题后可自动朗读英文题目，也可以手动重播当前题目。
- 支持录音练习，方便用户模拟复试现场口语作答。
- 支持显示 / 隐藏参考答案，用于答题后自我对照。
- 支持添加私人英文面试题，并自动翻译成中文，数据保存在浏览器本地。
- 支持响应式布局，电脑和移动端都可以使用。

## 使用场景

- 保研英语面试准备
- 考研复试英语口语问答训练
- 导师面试英文自我介绍练习
- 科研经历、项目经历、竞赛经历英文表达训练
- 面试追问和压力问题模拟练习

## 本地运行

```bash
npm install
npm run dev
```

然后在浏览器中打开：

```text
http://localhost:5173/
```

建议使用 Microsoft Edge 或 Chrome，以获得更稳定的朗读和录音体验。

## 部署

项目已配置 GitHub Pages 自动部署。推送到 `main` 或 `master` 分支后，GitHub Actions 会自动构建并发布网页。

部署成功后的访问地址示例：

```text
https://saber-55.github.io/english_meeting/
```
